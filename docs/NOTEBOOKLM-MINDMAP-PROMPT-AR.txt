برومبت لـ Notebook LM — إنشاء Mind Map لنظام «كلين ووتر»
================================================================================
انسخ المحتوى من القسم «ابدأ من هنا» حتى «انتهى البرومبت» والصقه في Notebook LM
كطلب واحد (Prompt)، ثم اطلب منه إخراج خريطة ذهنية (Mind Map) أو مخطط هيكلي.

--------------------------------------------------------------------------------
ابدأ من هنا
--------------------------------------------------------------------------------

أنت مساعد لبناء خريطة ذهنية (Mind Map) منظمة وواضحة باللغة العربية.

المطلوب منك:
1) إنشاء هيكل Mind Map متعدد المستويات لنظام إدارة أعمال يسمى «كلين ووتر — نظام إدارة متكامل».
2) استخدام عناوين قصيرة للعُقد (Nodes) وروابط منطقية بين الأب والابن.
3) عدم إضافة أي تفاصيل برمجية (لا أسماء ملفات، لا APIs، لا قواعد بيانات).
4) إخراج النتيجة بصيغة مناسبة للعرض: إما نص هرمي مرقّم، أو قائمة نقطية متداخلة، أو جدول (أب / ابن / وصف قصير)، حسب ما يسهّل تحويلها لخريطة في أداة الرسم.

بيانات النظام لبناء الخريطة:

【الجذر】
  كلين ووتر — نظام إدارة متكامل (ويب من المتصفح)

【مستوى أول — البداية】
  • الدخول والخروج (بريد وكلمة مرور)
  • التنقل: شريط جانبي = قائمة رئيسية + قسم إدارة (حسب الصلاحية)
  • مفهوم الفرع: قد يُفلتر المحتوى حسب فرع المستخدم

【مستوى أول — أدوار المستخدمين】
  • مدير النظام: وصول واسع + تتبع مناديب + نسخ احتياطي (إن وُجد)
  • أمين المخزن: لوحة تحكم، عملاء، فواتير، زيارات (مع تبويبات)، مخزون، مرتجعات، مشتريات، أقسام مخزون، مناطق، محطات، تقارير؛ غالباً بدون شاشة مالية رئيسية
  • خدمة العملاء: لوحة متابعة، متابعة عملاء، عملاء، فواتير، زيارات، صيانة، أوامر عمل
  • مندوب مبيعات: شاشة تسليم/مهام فقط بدون القائمة الكاملة

【مستوى أول — القائمة الرئيسية】
  • لوحة التحكم: ملخصات سريعة
  • العملاء: سجل، بحث، إضافة، تفاصيل (أجهزة، عقود، أقساط، صيانة شمعات حسب الشاشة)
  • الفواتير: إنشاء ومتابعة
  • الزيارات (صفحة موحّدة بثلاثة تبويبات):
      - إدارة الزيارات
      - الصيانة
      - أوامر العمل

【مستوى أول — قسم الإدارة】
  • المخزون: منتجات، كميات، حركات (وارد/منصرف/رصيد أول)، مواقع (مخزن رئيسي/معرض) إن وُجدت
  • أقسام المخزون: تصنيفات
  • المرتجعات
  • المشتريات
  • المحطات: بيانات محطة، عميل، ضمان، عقد صيانة، أقساط، سجل صيانة، أوامر شغل مرتبطة
  • القطاعات والمناطق
  • المناديب
  • المالية
  • المصروفات
  • سندات القبض
  • التقارير
  • (للمدير) تتبع المناديب
  • (للمدير) النسخ الاحتياطي

【مستوى ثانٍ — تدفقات عمل مختصرة (للربط في الخريطة كفروع فرعية)】
  عميل جديد → حفظ → فتح التفاصيل → (اختياري) جهاز/عقد/أقساط
  فاتورة → اختيار عميل → بنود → حفظ
  زيارات → تبويب زيارات / صيانة / أوامر عمل → إجراء داخل التبويب → حفظ
  أمر عمل → بيانات عميل وعنوان وهاتف → منتجات وكميات (مع مراعاة المتاح) → حفظ
  مخزون → اختيار نوع الحركة والموقع إن وُجد → منتج وكمية → حفظ → مراجعة السجل
  محطة → إضافة أو تعديل → حفظ → عرض تفاصيل/عقد/أوامر شغل → تسجيل صيانة عند الحاجة

【قيود التنسيق】
  • لا تذكر لغات برمجة أو أسماء تقنية.
  • اجعل العمق 3 إلى 4 مستويات كحد أقصى للوضوح.
  • إذا احتجت لاختصار، ادمج «المالية + المصروفات + سندات القبض» تحت عقدة واحدة اسمها «المالية والتحصيل» مع فروع فرعية.

الآن نفّذ المطلوب وأعد النتيجة جاهزة للنسخ إلى أداة رسم Mind Map.
